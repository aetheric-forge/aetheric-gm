# v0.2 milestone — live-play foundations

Version 0.2 begins turning the rules-enabled campaign workspace into a tool the game master can use directly at the table:

```text
Open a configured campaign
  -> roll dice manually or from declarative rules prose
  -> create a character from the pinned ruleset
  -> reopen and update a proper character sheet
```

The milestone is complete when a game master can create and reopen a character governed by the campaign's pinned ruleset, update its character-owned state, inspect its referenced rules content, and understand dice results initiated manually or from supported rules prose.

## Planned slices

1. [Roll animated dice](../stories/16-roll-animated-dice.md)
2. [Roll dice from rules text](../stories/19-roll-from-rules-text.md)
3. [Create a character with an ancestry](../stories/15-choose-character-ancestry.md)
4. [Use a character sheet during play](../stories/17-use-character-sheet.md)

The slices share a small vocabulary for character context, contextual roll requests, and stable rules references. Dedicated action and resource semantics can be added only when their declarative shapes are designed.

## Dice roller boundary

The first slice provides recognizable two-dimensional polyhedral dice, brief accessible animation, modifiers, advantage and disadvantage, contextual labels, readable totals, and recent-roll history. Results are generated before animation; animation only reveals them.

## Inline rules roll boundary

A companion slice lets rules authors embed a narrow declarative `[roll:expression|label]` token in supported prose. Valid tokens render as accessible roll links and open a compact modal that reuses the animated result presentation and shared session history. The full dice tray remains the surface for constructing manual rolls and reviewing history; rules packages cannot provide executable code or arbitrary presentation through roll tokens.

## Character sheet boundary

The third slice begins by creating a named character with an ancestry selected from the pinned ruleset's Character Creation catalog, then turns that ruleset's character-sheet definition into durable character-owned state. It renders scalar, embedded-record, and rules-reference fields coherently. Referenced ancestry and ability content remains read-only and may expose declarative inline rolls through the shared dice experience; the sheet does not infer resource or action semantics that its definition cannot express.

## Release boundary

Version 0.2 ends with Story 17. The release proves the complete character path from rules authoring through creation, persistence, reopening, and use. The NPC catalog begins the [v0.3 campaign-world milestone](v0.3.md) rather than extending this release.

## Deferred beyond v0.2

- three-dimensional dice and simulated physics;
- a generic character-sheet designer as a replacement for a focused ruleset sheet;
- full encounter, initiative, and combat automation;
- multiplayer or player-facing character sheets;
- permanent campaign-wide roll logging;
- NPC catalogs and campaign-owned NPC state;
- sophisticated migration or merge handling for evolving rules packages.
